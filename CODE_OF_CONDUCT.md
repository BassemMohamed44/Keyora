# Code of Conduct

## Our Standard

We want Keyora to be a welcoming and constructive project.

Participants are expected to:

- Be respectful and professional.
- Assume good intent.
- Give useful technical feedback.
- Accept constructive criticism.
- Focus on the code and the problem, not the person.
- Avoid harassment, discrimination, personal attacks, or deliberately disruptive behavior.

## Unacceptable Behavior

Examples include:

- Harassment or threats
- Personal attacks
- Hate speech
- Publishing private information without permission
- Deliberate disruption of discussions or development
- Trolling or repeated bad-faith behavior

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or take other reasonable actions when behavior violates this code of conduct.

If you experience or observe a serious violation, contact the project maintainers privately when possible.
